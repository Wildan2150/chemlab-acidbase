# Katalog model molekul

Katalog memuat **36 senyawa** dengan identitas dan rekaman SDF 3D PubChem yang diperiksa pada **10 November 2026 WIB**. Ini pilihan untuk eksplorasi struktur asam–basa dan perbandingan gugus fungsi; bukan seluruh database PubChem. Pencarian katalog bekerja lokal dan menerima nama Indonesia/Inggris, alias, rumus seperti H₂O₂ atau H2O2, dan CID. Filter kelompok dapat digabungkan dengan pencarian.

Model 3D tersedia setelah memilih **Buka aktivitas**. Memutar model hanya mengubah kamera. Molekul tunggal tidak menampilkan seluruh spesies dalam larutan, derajat ionisasi, atau pH. pH memerlukan konsentrasi dan kondisi larutan.

## Sumber, berkas, dan pemeliharaan

- Metadata tampilan/alias: [molecules.js](../src/data/molecules.js). ID ketiga molekul awal tetap 962, 222, dan 176.
- Struktur asli: public/molecules/{CID}.sdf, dari endpoint PubChem PUG REST dengan record_type=3d. Seluruh hidrogen eksplisit dipertahankan.
- [Manifest sumber](../public/molecules/sources.json) mencatat CID, rumus sumber, nama IUPAC, massa molar, jumlah atom/ikatan, URL, tanggal pengambilan, dan SHA-256. Perbedaan urutan unsur rumus PubChem tidak mengubah komposisi (misalnya H3N dan NH3).
- Pustaka npm 3dmol dipatok versi 2.5.5. [Lisensi lengkap](../public/licenses/3dmol-LICENSE.txt) memuat atribusi 3Dmol.js beserta komponen yang disertakannya.
- Penambahan senyawa memerlukan pengecekan identitas, rekaman 3D, komposisi, metadata, dan sumber. Model tanpa data 3D tidak dimasukkan dan tidak digantikan dengan koordinat buatan. Uji katalog memeriksa sumber, checksum, atom/ikatan, pencarian, dan pemulihan CID; uji browser merender seluruh katalog.

API diikuti dari [tutorial resmi 3Dmol.js](https://3dmol.org/doc/tutorial-code.html) dan [GLViewer](https://3dmol.org/doc/GLViewer.html). Rincian integrasi dan batas pengamatan ada pada [INTERACTIVE_ACTIVITIES.md](INTERACTIVE_ACTIVITIES.md).
