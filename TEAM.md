# Tim dan peran

Versi ini merupakan contoh pengajar, belum proyek kelompok mahasiswa.

| Peran                               | Pelaksana/bukti                                     |
| ----------------------------------- | --------------------------------------------------- |
| Pengarah ruang lingkup              | Pengajar: aplikasi siswa, asam–basa, mode lokal     |
| Implementasi dan pemeriksaan teknis | Codex: kode, dokumentasi, build, uji logika/browser |
| Validasi isi kimia dan pedagogik    | Pengajar; belum dicatat sebagai selesai             |
| Kelompok mahasiswa                  | Belum ditetapkan                                    |

Ketika dipakai sebagai baseline kelompok, isi identitas anggota dan pembagian kontribusi nyata. Dokumentasikan issue, branch, PR, review, dan perubahan kecil yang dapat dijelaskan setiap anggota. Riwayat kerja agent bukan bukti kontribusi individual mahasiswa.
